ToolStore Privacy Policy

Effective date: 15 October 2026

1. Introduction

ToolStore is a Chrome browser extension that provides a collection of everyday utilities through Chrome's side panel. This policy explains how ToolStore handles user information.

2. Information Collection

ToolStore does not collect, sell, or transmit users' personal information to external servers. Its tools are designed to operate locally in the user's browser. ToolStore does not use analytics or external APIs to collect user information.

3. Screenshot Functionality

ToolStore includes a Screenshot Toolkit that allows users to capture the currently visible browser tab. A screenshot is captured when the user activates the feature. The image is displayed within the extension and can be downloaded by the user. The screenshot functionality processes the image locally and does not upload it to an external server. Screenshots may contain sensitive information visible on the webpage the user chooses to capture.

4. Permissions

  • Side Panel: Displays the collection of tools in Chrome's side panel.
  • Active Tab: Supports screenshot capture of the visible browser tab when the user invokes the feature.

5. Data Storage and Sharing

ToolStore does not operate a server to store users' personal information. It does not sell or share user data with third parties. Information processed by individual tools remains within the browser unless the user independently chooses to save or export an output.

6. Children's Privacy

ToolStore is a general-purpose browser utility extension and is not specifically directed at collecting personal information from children.

7. Changes to This Policy

This policy may be updated if ToolStore's functionality or privacy practices change. The effective date will be updated when appropriate.
